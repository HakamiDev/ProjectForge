**ระบบปฏิบัติการสำหรับทีมเอเจนต์ AI** คำสั่งเดียวเปลี่ยนโฟลเดอร์ธรรมดาให้เป็นสำนักงานที่มีวินัย ประกอบด้วยบอร์ดกลางเพียงหนึ่งเดียวที่เอเจนต์ทุกตัวใช้ทำงานได้บนทุกแพลตฟอร์ม ด่านตรวจสอบคุณภาพที่เป็นอิสระ การกำกับดูแลการตัดสินใจ ร่องรอยการตรวจสอบที่ครบถ้วน ตัวชี้วัดประสิทธิภาพที่ส่งออกไปยัง Power BI ได้ และเว็บไซต์บริหารจัดการที่ทำงานจากไฟล์ HTML เพียงไฟล์เดียว

Python 3.9 ขึ้นไป ไม่มีการพึ่งพาไลบรารีอื่น ไม่ต้องใช้เซิร์ฟเวอร์ โอเพนซอร์ส ใช้สัญญาอนุญาต MIT

เว็บไซต์: https://hakamidev.github.io/ProjectForge/

## การติดตั้ง

คำสั่งบรรทัดเดียว วางลงในเทอร์มินัล คำสั่งนี้จะดาวน์โหลดเครื่องมือ เรียกใช้งาน ถามสี่คำถาม แล้วเปิดเว็บไซต์บริหารจัดการของคุณ

macOS และ Linux (Terminal):

```
curl -fsSL https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.sh | bash
```

Windows (PowerShell):

```
irm https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.ps1 | iex
```

เว็บไซต์ยังให้คุณเลือกแพลตฟอร์มและภาษาที่ต้องการล่วงหน้าได้ ทั้งสองค่าจะถูกใส่ลงในคำสั่งติดตั้งและถูกเลือกไว้ล่วงหน้าในตัวช่วยตั้งค่า

## ปัญหาที่แก้ได้

- **แชตลืมทุกอย่าง** กฎและเอกสารสรุปบทบาทอยู่ในโฟลเดอร์ ไม่ได้อยู่ในหน่วยความจำของแชต ดังนั้นแชตใดก็ได้สามารถทำงานต่อได้
- **เอเจนต์ทำงานชนกัน** บอร์ดเดียวที่มีหมายเลขกำกับ สถานะ "กำลังดำเนินการ" จะล็อกแถว และตัวป้องกันด้วย checksum จะป้องกันการเขียนที่ขัดแย้งกัน
- **ผลงานไม่ได้รับการตรวจสอบ** หัวหน้าฝ่ายประกันคุณภาพตัดสินว่าผ่านหรือไม่ผ่านก่อนที่สิ่งใดจะถึงมือเจ้าของ
- **การตัดสินใจค้างคา** มีการตัดสินใจที่เปิดค้างได้สูงสุดห้ารายการ และมีกฎ 48 ชั่วโมง เมื่อพ้นกำหนดแล้วให้ถือว่าข้อเสนอแนะมีผลเป็นการตัดสินใจ
- **ไม่มีการวัดผล** `report` แสดงอัตราการส่งมอบ ระยะเวลาวงจรงาน อัตราการผ่าน QA และภาระงานต่อบทบาท ส่วน `export` เขียนไฟล์ CSV สำหรับ Power BI
- **ไม่มีความรับผิดชอบที่ตรวจสอบได้** ทุกการเขียนลงบอร์ดจะถูกบันทึก ได้แก่ ใคร เมื่อไร และทำอะไร
- **ข้อมูลอ่อนไหวในเครื่องมือภายนอก** นโยบายข้อมูลที่มีผลผูกพัน พร้อมการจัดระดับชั้นข้อมูลและรายการเครื่องมือที่ได้รับอนุมัติ

## สิ่งที่คุณจะได้รับ

- **80 สาขาความเชี่ยวชาญ** (กลยุทธ์ ร้านอาหาร อสังหาริมทรัพย์ ซอฟต์แวร์ ทรัพยากรบุคคล การศึกษา และอื่น ๆ) พร้อมบทบาทสำเร็จรูปกว่า 330 บทบาทที่เพิ่มได้ด้วยการคลิกเพียงครั้งเดียว
- **ทักษะสำเร็จรูป 130 รายการใน 18 กลุ่ม** ทักษะคือไฟล์สั้น ๆ ที่อธิบายว่าควรใช้เมื่อใด ขั้นตอน ผลลัพธ์ และเกณฑ์การยอมรับ เพื่อให้พนักงานนำไปใช้แทนการทำงานแบบด้นสด
- **สี่แพลตฟอร์ม:** Claude, ChatGPT, Grok และ Gemini พนักงานแต่ละคนทำงานบนแพลตฟอร์มที่ต่างกันได้
- **ภาษาอินเทอร์เฟซ 27 ภาษา** บนเว็บไซต์และในตัวช่วยตั้งค่า ภาษาที่ต้องการคือภาษาที่ใช้บริหารระบบทั้งหมด และเป็นภาษาที่ใช้สื่อสารกับพนักงาน
- **เว็บไซต์บริหารจัดการ** จากไฟล์ HTML ไฟล์เดียว ประกอบด้วยบอร์ด ทีม การตัดสินใจ ตัวชี้วัด คลังคำสั่งสำเร็จรูป และกลไกแจ้งเตือนที่ระบุงานที่ล่าช้าหรือกำลังรอคุณ

## คำสั่ง

`new`, `build`, `watch`, `rows`, `add-row`, `set-status`, `add-role`, `add-skill`, `skills`, `decide`, `status`, `report`, `export`, `check`, `register`, `selftest`

## แพลตฟอร์ม

| แพลตฟอร์ม | วิธีตั้งค่าทีม |
| --- | --- |
| Claude | สร้างโปรเจกต์ที่ตั้งชื่อตามโปรเจกต์ของคุณ แล้วเพิ่มโฟลเดอร์ที่สร้างขึ้น |
| ChatGPT | สร้างโปรเจกต์แล้วอัปโหลดไฟล์ในโฟลเดอร์ |
| Grok | สร้างโปรเจกต์ วางคำสั่ง Compass ลงในคำแนะนำของโปรเจกต์ แล้วเพิ่มไฟล์ |
| Gemini | สร้าง Gem สำหรับพนักงานแต่ละคน วางคำสั่งของพนักงานลงในคำแนะนำ แล้วเพิ่มไฟล์ภายใต้ Knowledge |

อัปโหลดไฟล์จากโฟลเดอร์โปรเจกต์ในตำแหน่งเดิม และอัปโหลดซ้ำเฉพาะไฟล์ที่เปลี่ยนแปลง เท่าที่เราทราบ Grok และ Gemini ไม่เขียนลงโฟลเดอร์โดยตรง ดังนั้นคุณต้องย้ายผลลัพธ์ของทั้งสองเข้าโฟลเดอร์ด้วยตนเอง ขั้นตอนเหล่านี้อ้างอิงเอกสารสาธารณะ ณ เวลาที่เขียน ส่วนอินเทอร์เฟซและข้อจำกัดนั้นกำหนดโดยแพลตฟอร์มเหล่านั้นและอาจเปลี่ยนแปลงได้

## ข้อจำกัดในปัจจุบัน

- ตัวช่วยตั้งค่าและเว็บไซต์แสดงผลได้ใน 27 ภาษา แต่ไฟล์โปรเจกต์ที่สร้างขึ้น (กฎ เอกสารสรุปบทบาท บอร์ด) และเว็บไซต์บริหารจัดการยังเขียนเป็นภาษาอาหรับในขณะนี้ พนักงานจะได้รับแจ้งให้ทำงานด้วยภาษาใดและตอบคุณเป็นภาษานั้น
- ชื่อไฟล์ คำสั่ง และคำแสดงสถานะของบอร์ดยังคงเป็นภาษาอาหรับ เพราะเครื่องมืออ่านค่าเหล่านี้ตามตัวอักษร
- การติดตั้งบน Windows ยังไม่ได้ทดสอบบนเครื่องจริง

## สำหรับนักพัฒนา

```
git clone https://github.com/HakamiDev/ProjectForge.git
cd ProjectForge
python3 -m forge
python3 -I tests/testforge.py
python3 -I tools/build-single.py
python3 -I tools/build-site.py
```

ซอร์สโค้ดอยู่ใน `forge/` ส่วน `tools/build-single.py` สร้างเครื่องมือแบบไฟล์เดียวไว้ใน `dist/` เทมเพลตอยู่ใน `forge/templates/` และเว็บไซต์สาธารณะอยู่ใน `site/`
