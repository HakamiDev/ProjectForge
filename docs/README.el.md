**Ένα λειτουργικό σύστημα για μια ομάδα πρακτόρων τεχνητής νοημοσύνης.** Μία εντολή μετατρέπει έναν απλό φάκελο σε πειθαρχημένο γραφείο: έναν ενιαίο πίνακα εργασιών από τον οποίο εργάζεται κάθε πράκτορας, σε οποιαδήποτε πλατφόρμα· μια ανεξάρτητη πύλη ποιότητας· διακυβέρνηση αποφάσεων· πλήρες ίχνος ελέγχου· δείκτες απόδοσης που εξάγονται στο Power BI· και έναν ιστότοπο διαχείρισης που λειτουργεί από ένα μόνο αρχείο HTML.

Python 3.9 ή νεότερο, χωρίς εξαρτήσεις, χωρίς διακομιστή. Ανοιχτού κώδικα, με άδεια MIT.

Ιστότοπος: https://hakamidev.github.io/ProjectForge/

## Εγκατάσταση

Μία γραμμή, που επικολλάται σε τερματικό. Κατεβάζει το εργαλείο, το εκτελεί, κάνει τέσσερις ερωτήσεις και στη συνέχεια ανοίγει τον ιστότοπο διαχείρισής σας.

macOS και Linux (Terminal):

```
curl -fsSL https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.sh | bash
```

Windows (PowerShell):

```
irm https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.ps1 | iex
```

Ο ιστότοπος σάς επιτρέπει επίσης να επιλέξετε εκ των προτέρων την πλατφόρμα και την προτιμώμενη γλώσσα· και οι δύο επιλογές μεταφέρονται στην εντολή εγκατάστασης και προεπιλέγονται στον οδηγό.

## Τι επιλύει

- **Οι συνομιλίες ξεχνούν.** Οι κανόνες και τα υπομνήματα ρόλων βρίσκονται στον φάκελο και όχι στη μνήμη της συνομιλίας, ώστε κάθε συνομιλία να μπορεί να συνεχίσει την εργασία.
- **Οι πράκτορες συγκρούονται.** Ένας αριθμημένος πίνακας· η κατάσταση «σε εξέλιξη» κλειδώνει μια γραμμή· ένας έλεγχος αθροίσματος ελέγχου αποτρέπει τις συγκρουόμενες εγγραφές.
- **Αναξιόπιστα αποτελέσματα.** Ένας επικεφαλής διασφάλισης ποιότητας κρίνει την επιτυχία ή την αποτυχία πριν από οτιδήποτε φτάσει στον ιδιοκτήτη.
- **Αποφάσεις που καθυστερούν.** Το πολύ πέντε ανοιχτές αποφάσεις και κανόνας των 48 ωρών, μετά τον οποίο ισχύει η εισήγηση.
- **Τίποτα δεν μετριέται.** Η εντολή `report` δίνει ποσοστό παράδοσης, χρόνο κύκλου, ποσοστό επιτυχίας ποιοτικού ελέγχου και φόρτο ανά ρόλο· η εντολή `export` γράφει αρχεία CSV για το Power BI.
- **Καμία λογοδοσία.** Κάθε εγγραφή στον πίνακα καταγράφεται: ποιος, πότε και τι.
- **Ευαίσθητα δεδομένα σε εξωτερικά εργαλεία.** Δεσμευτική πολιτική δεδομένων με ταξινόμηση και εγκεκριμένα εργαλεία.

## Τι αποκτάτε

- **80 ειδικεύσεις** (στρατηγική, εστίαση, ακίνητα, λογισμικό, ανθρώπινο δυναμικό, εκπαίδευση και άλλες) με περισσότερους από 330 έτοιμους ρόλους που προσθέτετε με ένα κλικ.
- **130 έτοιμες δεξιότητες σε 18 ομάδες.** Μια δεξιότητα είναι ένα σύντομο αρχείο που περιγράφει πότε χρησιμοποιείται, τα βήματά της, το αποτέλεσμά της και το κριτήριο αποδοχής της, ώστε ο εργαζόμενος να την εφαρμόζει αντί να αυτοσχεδιάζει.
- **Τέσσερις πλατφόρμες:** Claude, ChatGPT, Grok και Gemini. Κάθε εργαζόμενος μπορεί να εργάζεται σε διαφορετική πλατφόρμα.
- **27 γλώσσες διεπαφής** στον ιστότοπο και στον οδηγό. Η προτιμώμενη γλώσσα είναι η γλώσσα διαχείρισης ολόκληρου του συστήματος και αυτή που χρησιμοποιείται με τους εργαζόμενους.
- **Ένας ιστότοπος διαχείρισης** από ένα μόνο αρχείο HTML: πίνακας, ομάδα, αποφάσεις, δείκτες, βιβλιοθήκη έτοιμων εντολών και μηχανισμός επισήμανσης που επισημαίνει ό,τι καθυστερεί ή περιμένει εσάς.

## Εντολές

`new`, `build`, `watch`, `rows`, `add-row`, `set-status`, `add-role`, `add-skill`, `skills`, `decide`, `status`, `report`, `export`, `check`, `register`, `selftest`.

## Πλατφόρμες

| Πλατφόρμα | Πώς στήνεται η ομάδα |
| --- | --- |
| Claude | Δημιουργήστε ένα έργο με το όνομα του έργου σας και προσθέστε τον φάκελο που δημιουργήθηκε. |
| ChatGPT | Δημιουργήστε ένα έργο και ανεβάστε τα αρχεία του φακέλου. |
| Grok | Δημιουργήστε ένα έργο, επικολλήστε την εντολή Compass στις οδηγίες του και προσθέστε τα αρχεία. |
| Gemini | Δημιουργήστε ένα Gem για κάθε εργαζόμενο, επικολλήστε την εντολή του στις οδηγίες και προσθέστε τα αρχεία στην ενότητα Knowledge. |

Ανεβάστε τα αρχεία από τον φάκελο του έργου στην αρχική του θέση και ανεβάστε ξανά όσα αλλάζουν. Εξ όσων γνωρίζουμε, το Grok και το Gemini δεν γράφουν απευθείας στον φάκελο, οπότε μεταφέρετε μόνοι σας τα αποτελέσματά τους στον φάκελο. Τα βήματα βασίζονται στη δημόσια τεκμηρίωση κατά τον χρόνο συγγραφής· οι διεπαφές και τα όρια καθορίζονται από τις συγκεκριμένες πλατφόρμες και ενδέχεται να αλλάξουν.

## Τρέχοντες περιορισμοί

- Ο οδηγός και ο ιστότοπος εμφανίζονται σε 27 γλώσσες, αλλά τα αρχεία του έργου που δημιουργούνται (κανόνες, υπομνήματα ρόλων, πίνακας) και ο ιστότοπος διαχείρισης είναι προς το παρόν γραμμένα στα αραβικά. Οι εργαζόμενοι ενημερώνονται σε ποια γλώσσα να εργάζονται και σας απαντούν σε αυτήν.
- Τα ονόματα αρχείων, οι εντολές και οι λέξεις κατάστασης του πίνακα παραμένουν στα αραβικά, επειδή το εργαλείο τα διαβάζει κατά γράμμα.
- Η εγκατάσταση σε Windows δεν έχει ακόμη δοκιμαστεί σε πραγματικό μηχάνημα.

## Για προγραμματιστές

```
git clone https://github.com/HakamiDev/ProjectForge.git
cd ProjectForge
python3 -m forge
python3 -I tests/testforge.py
python3 -I tools/build-single.py
python3 -I tools/build-site.py
```

Ο πηγαίος κώδικας βρίσκεται στο `forge/`· το `tools/build-single.py` παράγει το εργαλείο ενός αρχείου στο `dist/`. Τα πρότυπα βρίσκονται στο `forge/templates/` και ο δημόσιος ιστότοπος στο `site/`.
