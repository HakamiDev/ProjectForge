**مصنوعی ذہانت کے ایجنٹوں کی ٹیم کے لیے ایک آپریٹنگ سسٹم۔** ایک کمانڈ ایک سادہ فولڈر کو منظم دفتر میں بدل دیتی ہے: ایک واحد بورڈ جس سے ہر ایجنٹ کسی بھی پلیٹ فارم پر کام کرتا ہے؛ معیار کا ایک آزاد دروازہ؛ فیصلوں کا نظم و نسق؛ مکمل آڈٹ ٹریل؛ کارکردگی کے اشاریے جو Power BI میں برآمد ہوتے ہیں؛ اور ایک انتظامی ویب سائٹ جو ایک ہی HTML فائل سے چلتی ہے۔

Python 3.9 یا اس کے بعد کا ورژن، کوئی انحصار نہیں، کوئی سرور نہیں۔ اوپن سورس، MIT لائسنس کے تحت۔

ویب سائٹ: https://hakamidev.github.io/ProjectForge/

## انسٹالیشن

ایک لائن، جو ٹرمینل میں پیسٹ کی جاتی ہے۔ یہ ٹول ڈاؤن لوڈ کرتی ہے، اسے چلاتی ہے، چار سوال پوچھتی ہے، پھر آپ کی انتظامی ویب سائٹ کھولتی ہے۔

macOS اور Linux (Terminal):

```
curl -fsSL https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.sh | bash
```

Windows (PowerShell):

```
irm https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.ps1 | iex
```

ویب سائٹ آپ کو پہلے سے اپنا پلیٹ فارم اور ترجیحی زبان منتخب کرنے کی سہولت بھی دیتی ہے؛ دونوں انتخابات انسٹالیشن کمانڈ میں شامل ہو جاتے ہیں اور وزرڈ میں پہلے سے منتخب ہوتے ہیں۔

## یہ کن مسائل کو حل کرتا ہے

- **چیٹس بھول جاتی ہیں۔** قواعد اور کرداروں کے ہدایت نامے فولڈر میں رہتے ہیں، چیٹ کی یادداشت میں نہیں، اس لیے کوئی بھی چیٹ کام کو دوبارہ شروع کر سکتی ہے۔
- **ایجنٹ آپس میں ٹکراتے ہیں۔** ایک شمار شدہ بورڈ؛ «زیرِ عمل» کی حالت ایک قطار کو مقفل کر دیتی ہے؛ چیک سم کی نگرانی متضاد اندراجات کو روکتی ہے۔
- **غیر جانچا ہوا کام۔** مالک تک کچھ بھی پہنچنے سے پہلے معیار کی یقین دہانی کا سربراہ پاس یا فیل کا فیصلہ کرتا ہے۔
- **رکے ہوئے فیصلے۔** زیادہ سے زیادہ پانچ کھلے فیصلے، اور 48 گھنٹے کا اصول جس کے بعد سفارش نافذ ہو جاتی ہے۔
- **کسی چیز کی پیمائش نہیں ہوتی۔** `report` ترسیل کی شرح، سائیکل ٹائم، کوالٹی چیک میں کامیابی کی شرح اور ہر کردار کا بوجھ دکھاتی ہے؛ `export` Power BI کے لیے CSV فائلیں لکھتی ہے۔
- **جواب دہی کا فقدان۔** بورڈ پر ہر تحریر درج کی جاتی ہے: کس نے، کب اور کیا۔
- **بیرونی ٹولز میں حساس ڈیٹا۔** درجہ بندی اور منظور شدہ ٹولز کے ساتھ ڈیٹا کی پابند پالیسی۔

## آپ کو کیا ملتا ہے

- **80 تخصصات** (حکمتِ عملی، ریستوراں، رئیل اسٹیٹ، سافٹ ویئر، انسانی وسائل، تعلیم اور مزید) اور 330 سے زائد تیار کردار جنہیں آپ ایک کلک میں شامل کرتے ہیں۔
- **18 گروہوں میں 130 تیار مہارتیں۔** مہارت ایک مختصر فائل ہے جو بیان کرتی ہے کہ اسے کب استعمال کرنا ہے، اس کے مراحل، اس کا نتیجہ اور اس کا معیارِ قبولیت، تاکہ ملازم اسے بروئے کار لائے، اندازے سے کام نہ کرے۔
- **چار پلیٹ فارم:** Claude، ChatGPT، Grok اور Gemini۔ ہر ملازم مختلف پلیٹ فارم پر کام کر سکتا ہے۔
- **27 انٹرفیس زبانیں** ویب سائٹ اور وزرڈ میں۔ ترجیحی زبان پورے نظام کو چلانے کی زبان ہے اور وہی ملازمین کے ساتھ استعمال ہوتی ہے۔
- **ایک انتظامی ویب سائٹ** ایک HTML فائل سے: بورڈ، ٹیم، فیصلے، اشاریے، تیار کمانڈز کی لائبریری، اور توجہ کا انجن جو بتاتا ہے کہ کیا تاخیر کا شکار ہے یا آپ کا منتظر ہے۔

## کمانڈز

`new`، `build`، `watch`، `rows`، `add-row`، `set-status`، `add-role`، `add-skill`، `skills`، `decide`، `status`، `report`، `export`، `check`، `register`، `selftest`۔

## پلیٹ فارمز

| پلیٹ فارم | ٹیم کیسے ترتیب دی جاتی ہے |
| --- | --- |
| Claude | اپنے پروجیکٹ کے نام سے ایک پروجیکٹ بنائیں اور تیار شدہ فولڈر شامل کریں۔ |
| ChatGPT | ایک پروجیکٹ بنائیں اور فولڈر کی فائلیں اپ لوڈ کریں۔ |
| Grok | ایک پروجیکٹ بنائیں، Compass کمانڈ کو اس کی ہدایات میں پیسٹ کریں، اور فائلیں شامل کریں۔ |
| Gemini | ہر ملازم کے لیے ایک Gem بنائیں، اس کی کمانڈ ہدایات میں پیسٹ کریں، اور فائلیں Knowledge کے تحت شامل کریں۔ |

پروجیکٹ فولڈر کی فائلیں اس کے اصل مقام سے اپ لوڈ کریں اور جو فائلیں تبدیل ہوں انہیں دوبارہ اپ لوڈ کریں۔ ہمارے علم کے مطابق Grok اور Gemini فولڈر میں براہِ راست نہیں لکھتے، اس لیے ان کے نتائج خود فولڈر میں منتقل کریں۔ یہ مراحل تحریر کے وقت کی عوامی دستاویزات کے مطابق ہیں؛ انٹرفیس اور حدود ان پلیٹ فارمز کے اپنے تعین کردہ ہیں اور بدل سکتے ہیں۔

## موجودہ حدود

- وزرڈ اور ویب سائٹ 27 زبانوں میں دکھائے جاتے ہیں، لیکن تیار ہونے والی پروجیکٹ فائلیں (قواعد، کرداروں کے ہدایت نامے، بورڈ) اور انتظامی ویب سائٹ فی الحال عربی میں لکھی جاتی ہیں۔ ملازمین کو بتایا جاتا ہے کہ کس زبان میں کام کرنا ہے اور وہ اسی میں آپ کو جواب دیتے ہیں۔
- فائلوں کے نام، کمانڈز اور بورڈ کی حالت کے الفاظ عربی ہی میں رہتے ہیں کیونکہ ٹول انہیں حرف بہ حرف پڑھتا ہے۔
- Windows پر انسٹالیشن کا ابھی تک کسی حقیقی مشین پر تجربہ نہیں کیا گیا۔

## ڈویلپرز کے لیے

```
git clone https://github.com/HakamiDev/ProjectForge.git
cd ProjectForge
python3 -m forge
python3 -I tests/testforge.py
python3 -I tools/build-single.py
python3 -I tools/build-site.py
```

سورس کوڈ `forge/` میں ہے؛ `tools/build-single.py` ایک فائل والا ٹول `dist/` میں تیار کرتا ہے۔ ٹیمپلیٹس `forge/templates/` میں اور عوامی ویب سائٹ `site/` میں ہیں۔
