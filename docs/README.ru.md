**Операционная система для команды ИИ-агентов.** Одна команда превращает обычную папку в организованный офис: единая доска, с которой работают все агенты на любой платформе; независимый контроль качества; управление решениями; полный журнал аудита; показатели эффективности с экспортом в Power BI и сайт управления, работающий из одного HTML-файла.

Python 3.9 или новее, без зависимостей, без сервера. Открытый исходный код, лицензия MIT.

Сайт: https://hakamidev.github.io/ProjectForge/

## Установка

Одна строка, вставленная в терминал. Она загружает инструмент, запускает его, задаёт четыре вопроса и затем открывает ваш сайт управления.

macOS и Linux (Terminal):

```
curl -fsSL https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.sh | bash
```

Windows (PowerShell):

```
irm https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.ps1 | iex
```

Сайт также позволяет заранее выбрать платформу и предпочитаемый язык; оба параметра попадают в команду установки и заранее выбираются в мастере.

## Какие задачи решает

- **Чаты забывают.** Правила и описания ролей хранятся в папке, а не в памяти чата, поэтому любой чат может продолжить работу.
- **Агенты мешают друг другу.** Одна нумерованная доска; статус «в работе» блокирует строку; проверка контрольной суммы предотвращает конфликтующие записи.
- **Непроверенный результат.** Руководитель по обеспечению качества выносит решение «пройдено» или «не пройдено», прежде чем что-либо попадёт к владельцу.
- **Зависшие решения.** Не более пяти открытых решений и правило 48 часов: по его истечении рекомендация вступает в силу.
- **Ничто не измеряется.** `report` показывает долю выполненных задач, время цикла, долю успешных проверок качества и нагрузку по ролям; `export` записывает файлы CSV для Power BI.
- **Нет подотчётности.** Каждая запись на доске фиксируется: кто, когда и что изменил.
- **Конфиденциальные данные во внешних инструментах.** Обязательная политика данных с классификацией и перечнем утверждённых инструментов.

## Что вы получаете

- **80 специализаций** (стратегия, рестораны, недвижимость, программное обеспечение, HR, образование и другие) и более 330 готовых ролей, которые добавляются одним щелчком.
- **130 готовых навыков в 18 группах.** Навык — это короткий файл с описанием того, когда его применять, его шагов, результата и критерия приёмки, так что сотрудник действует по нему, а не импровизирует.
- **Четыре платформы:** Claude, ChatGPT, Grok и Gemini. Каждый сотрудник может работать на своей платформе.
- **13 языков интерфейса** на сайте и в мастере. Предпочитаемый язык — это язык управления всей системой и общения с сотрудниками.
- **Сайт управления** из одного HTML-файла: доска, команда, решения, показатели, библиотека готовых команд и механизм внимания, который отмечает просроченное и то, что ждёт вашего ответа.

## Команды

`new`, `build`, `watch`, `rows`, `add-row`, `set-status`, `add-role`, `add-skill`, `skills`, `decide`, `status`, `report`, `export`, `check`, `register`, `selftest`.

## Платформы

| Платформа | Как настраивается команда |
| --- | --- |
| Claude | Создайте проект с названием вашего проекта и добавьте сгенерированную папку. |
| ChatGPT | Создайте проект и загрузите файлы из папки. |
| Grok | Создайте проект, вставьте команду Compass в его инструкции и добавьте файлы. |
| Gemini | Создайте Gem для каждого сотрудника, вставьте его команду в инструкции и добавьте файлы в раздел Knowledge. |

Загружайте файлы из папки проекта в её исходном расположении и повторно загружайте изменившиеся. Насколько нам известно, Grok и Gemini не записывают данные в папку напрямую, поэтому переносите их результаты в папку самостоятельно. Описанные шаги основаны на общедоступной документации на момент написания; интерфейсы и ограничения определяются этими платформами и могут измениться.

## Текущие ограничения

- Мастер и сайт отображаются на 13 языках, однако создаваемые файлы проекта (правила, описания ролей, доска) и сайт управления пока написаны на арабском языке. Сотрудникам сообщается, на каком языке работать, и они отвечают вам на нём.
- Имена файлов, команды и слова статусов доски остаются на арабском языке, поскольку инструмент считывает их буквально.
- Установка в Windows пока не проверялась на реальном компьютере.

## Для разработчиков

```
git clone https://github.com/HakamiDev/ProjectForge.git
cd ProjectForge
python3 -m forge
python3 -I tests/testforge.py
python3 -I tools/build-single.py
python3 -I tools/build-site.py
```

Исходный код находится в `forge/`; `tools/build-single.py` создаёт однофайловый инструмент в `dist/`. Шаблоны находятся в `forge/templates/`, общедоступный сайт — в `site/`.
