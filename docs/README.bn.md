**AI এজেন্টদের একটি দলের জন্য অপারেটিং সিস্টেম।** একটিমাত্র কমান্ড একটি সাধারণ ফোল্ডারকে সুশৃঙ্খল অফিসে রূপান্তরিত করে: একটি অভিন্ন বোর্ড, যা থেকে প্রতিটি এজেন্ট যেকোনো প্ল্যাটফর্মে কাজ করে; একটি স্বাধীন মান-যাচাই গেট; সিদ্ধান্ত-পরিচালনা ব্যবস্থা; সম্পূর্ণ অডিট ট্রেইল; Power BI-তে রপ্তানিযোগ্য পারফরম্যান্স মেট্রিক্স; এবং একটিমাত্র HTML ফাইল থেকে চলা ব্যবস্থাপনা সাইট।

Python 3.9 বা পরবর্তী সংস্করণ, কোনো নির্ভরতা নেই, কোনো সার্ভার নেই। ওপেন সোর্স, MIT লাইসেন্সের অধীনে।

ওয়েবসাইট: https://hakamidev.github.io/ProjectForge/

## ইনস্টল

একটি লাইন, যা টার্মিনালে পেস্ট করতে হবে। এটি টুলটি ডাউনলোড করে, চালায়, চারটি প্রশ্ন করে এবং তারপর আপনার ব্যবস্থাপনা সাইট খুলে দেয়।

macOS ও Linux (Terminal):

```
curl -fsSL https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.sh | bash
```

Windows (PowerShell):

```
irm https://raw.githubusercontent.com/HakamiDev/ProjectForge/main/install.ps1 | iex
```

সাইটে আপনি আগেই প্ল্যাটফর্ম ও পছন্দের ভাষা বেছে নিতে পারেন; দুটিই ইনস্টল কমান্ডে যুক্ত হয় এবং উইজার্ডে আগে থেকেই নির্বাচিত থাকে।

## এটি কী সমাধান করে

- **চ্যাট ভুলে যায়।** নিয়ম ও ভূমিকা-নির্দেশিকা ফোল্ডারে থাকে, চ্যাটের স্মৃতিতে নয়, তাই যেকোনো চ্যাট কাজটি আবার শুরু করতে পারে।
- **এজেন্টদের মধ্যে সংঘাত।** একটি ক্রমিক সংখ্যাযুক্ত বোর্ড; "চলমান" অবস্থা সারিটিকে লক করে; চেকসাম গার্ড পরস্পরবিরোধী লেখা প্রতিরোধ করে।
- **যাচাইহীন আউটপুট।** মালিকের কাছে কিছু পৌঁছানোর আগে মান নিশ্চয়তা প্রধান পাস বা ফেলের রায় দেন।
- **আটকে থাকা সিদ্ধান্ত।** সর্বোচ্চ পাঁচটি উন্মুক্ত সিদ্ধান্ত, এবং ৪৮ ঘণ্টার নিয়ম, যার পরে সুপারিশটি কার্যকর হয়।
- **কিছুই পরিমাপ করা হয় না।** `report` প্রতিটি ভূমিকার ডেলিভারি হার, সাইকেল টাইম, QA পাস হার ও কাজের চাপ দেয়; `export` Power BI-র জন্য CSV ফাইল লেখে।
- **কোনো জবাবদিহি নেই।** বোর্ডে প্রতিটি লেখা নথিভুক্ত হয়: কে, কখন এবং কী।
- **বাইরের টুলে সংবেদনশীল ডেটা।** শ্রেণিবিন্যাস ও অনুমোদিত টুলসহ একটি বাধ্যতামূলক ডেটা নীতি।

## আপনি কী পাবেন

- **৮০টি বিশেষায়ন** (কৌশল, রেস্তোরাঁ, রিয়েল এস্টেট, সফটওয়্যার, মানবসম্পদ, শিক্ষা ও আরও অনেক) এবং ৩৩০-এর বেশি প্রস্তুত ভূমিকা, যা এক ক্লিকে যোগ করা যায়।
- **১৮টি গ্রুপে ১৩০টি প্রস্তুত স্কিল।** স্কিল হলো একটি ছোট ফাইল, যাতে বর্ণনা থাকে কখন এটি ব্যবহার করতে হবে, এর ধাপ, এর আউটপুট এবং এর গ্রহণযোগ্যতার মানদণ্ড, যাতে কর্মী এলোমেলোভাবে কাজ না করে এটি প্রয়োগ করেন।
- **চারটি প্ল্যাটফর্ম:** Claude, ChatGPT, Grok ও Gemini। প্রতিটি কর্মী আলাদা প্ল্যাটফর্মে কাজ করতে পারেন।
- ওয়েবসাইট ও উইজার্ডে **২৭টি ইন্টারফেস ভাষা।** পছন্দের ভাষাই সমগ্র ব্যবস্থা পরিচালনার ভাষা এবং কর্মীদের সঙ্গে যোগাযোগের ভাষা।
- **একটি HTML ফাইলের ব্যবস্থাপনা সাইট:** বোর্ড, দল, সিদ্ধান্ত, মেট্রিক্স, প্রস্তুত কমান্ডের লাইব্রেরি এবং একটি অ্যাটেনশন ইঞ্জিন, যা দেখায় কোনটি বিলম্বিত বা আপনার অপেক্ষায় আছে।

## প্ল্যাটফর্ম

| প্ল্যাটফর্ম | দল কীভাবে সাজানো হয় |
| --- | --- |
| Claude | আপনার প্রকল্পের নামে একটি প্রজেক্ট তৈরি করুন এবং তৈরি হওয়া ফোল্ডারটি যোগ করুন। |
| ChatGPT | একটি প্রজেক্ট তৈরি করুন এবং ফোল্ডারের ফাইলগুলো আপলোড করুন। |
| Grok | একটি প্রজেক্ট তৈরি করুন, Compass কমান্ডটি তার নির্দেশনায় পেস্ট করুন এবং ফাইলগুলো যোগ করুন। |
| Gemini | প্রতিটি কর্মীর জন্য একটি Gem তৈরি করুন, তার কমান্ড নির্দেশনায় পেস্ট করুন এবং ফাইলগুলো Knowledge-এর অধীনে যোগ করুন। |

প্রজেক্ট ফোল্ডারের ফাইলগুলো তার মূল অবস্থান থেকে আপলোড করুন এবং যা বদলায় তা আবার আপলোড করুন। আমাদের জানা মতে Grok ও Gemini সরাসরি ফোল্ডারে লেখে না, তাই তাদের আউটপুট নিজে ফোল্ডারে সরিয়ে নিন। ধাপগুলো লেখার সময়কার সর্বজনীন ডকুমেন্টেশন অনুসরণ করে; ইন্টারফেস ও সীমা ওই প্ল্যাটফর্মগুলো নির্ধারণ করে এবং তা বদলাতে পারে।

## বর্তমান সীমাবদ্ধতা

- উইজার্ড ও ওয়েবসাইট ২৭টি ভাষায় দেখা যায়, কিন্তু তৈরি হওয়া প্রকল্পের ফাইল (নিয়ম, ভূমিকা-নির্দেশিকা, বোর্ড) এবং ব্যবস্থাপনা সাইট আপাতত আরবিতে লেখা হয়। কর্মীদের জানানো হয় কোন ভাষায় কাজ করতে হবে এবং তাঁরা আপনাকে সেই ভাষাতেই উত্তর দেন।
- ফাইলের নাম, কমান্ড এবং বোর্ডের অবস্থাবাচক শব্দ আরবিতেই থাকে, কারণ টুলটি সেগুলো হুবহু পড়ে।
- Windows-এ ইনস্টলেশন এখনও কোনো প্রকৃত মেশিনে পরীক্ষা করা হয়নি।

## ডেভেলপারদের জন্য

```
git clone https://github.com/HakamiDev/ProjectForge.git
cd ProjectForge
python3 -m forge
python3 -I tests/testforge.py
python3 -I tools/build-single.py
python3 -I tools/build-site.py
```

সোর্স কোড `forge/`-এ আছে; `tools/build-single.py` একক-ফাইলের টুলটি `dist/`-এ তৈরি করে। টেমপ্লেট `forge/templates/`-এ এবং সর্বজনীন সাইট `site/`-এ আছে।
