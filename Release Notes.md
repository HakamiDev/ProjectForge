# v2.1.5: desktop icon removed

Released: 31 October 2026. Previous published release: v2.1.4.

- Removed the desktop icon feature completely: the wizard button, the `shortcut` command, the local `/api/shortcut` route, the launcher code and its test. Start the wizard with `python3 -I "Project Forge 1.py" gui` or with the install line. An icon created by an earlier version can be deleted from the desktop; the folder `Project Forge` in the application data directory (macOS: `~/Library/Application Support/Project Forge`) can be deleted too.

## v2.1.4: desktop icon fix

Released: 31 October 2026. Previous published release: v2.1.3.

- macOS desktop icon: the launcher no longer rejects the Command Line Tools Python (the one installed with Xcode tools); it starts the Python that created it, then tries the common locations, and logs every attempt to `~/Library/Logs/Project Forge.log`. The failure alert now points to that log.

## v2.1.3: fixes

Released: 31 October 2026. Previous published release: v2.1.2.

- Desktop icon (macOS): the launcher now records the exact Python that installed it and tries the usual install locations (Homebrew, python.org, conda) before the system one, writes its output to `~/Library/Logs/Project Forge.log`, shows an alert when no Python 3.9 or newer is found, is signed locally, and opens the page with the system `open` command.
- Wizard finish screen: the check mark, the project name and the project path are green (light and dark).
- Wizard style sheet: a malformed shadow value stopped the browser from reading every rule after it, so the pill buttons and fields fell back to defaults. Fixed.

Released: 31 October 2026. Previous published release: v1.1.9.

- Full localization in eight languages (Arabic, English, Spanish, Macedonian, German, Simplified Chinese, Portuguese, Russian): the language chosen at the start applies to every generated file and name, role briefs, skills, the command library, reports, the management site, the wizard and the project's own tool, including its terminal messages and `argparse` headings. - Public site rebuilt as a single column in the eight languages: language bar first, then Install, Features and How it works. It opens in English and the install line carries `FORGE_LANGUAGE` and `FORGE_PLATFORM`. Generated by `tools/build-site.py` from `tools/site/i18n.py`.
- Time zone: timestamps and due dates follow the user's local time zone instead of a fixed offset.
- Catalogue wording made vendor-neutral in all languages (no product names in the automation and data skills).
- Removed: the 13-language `docs/README.*` set (superseded by the eight-language policy), `site/template.html`, `site/en.json`, `site/og.html` and the English display layer of the office (replaced by full localization).
- Checks: 26 unit tests, 3 release checks, `selftest`, and a browser pass of the office in four languages, the wizard and the public site in eight languages (light and dark, 1280 and 390).
- Not claimed: native-speaker review, a clean-device install on Windows.
